# Design decisions that change the output

## Hierarchy and content

For event discovery: title → date/time/location → supporting copy → registration path. A reminder may need date/action as the main emphasis; the bundled title-led system is not automatically suitable. One dominant message is a starting point, not a universal law. This is a measured layout, not a general constraint solver.

Do not delete mandatory facts to pass geometry. If locked information cannot fit, change composition or reject. Long content is an input/art-direction problem before it is a font-size problem. Brand rules override defaults; never auto-substitute a new brand colour to silence a warning.

## Adaptation

Wide expands the text/visual columns; portrait adds space. Inspect faces, labels and logos; declared crop protection cannot infer what matters. A transparent logo must keep its approved variant and proportions. Use built-in original motifs only if appropriate to the brief.

Font floors are project heuristics at specified canvas sizes. A 1080px graphic shown 360px wide reduces text by 3×. Inside the canvas is not necessarily readable. Check the actual display size before delivery.

## Repair loop

Read the failed role → inspect source and final PNG → adjust breaks or layout → propose shorter unlocked copy if needed → rerender to a new revision. Stop after two targeted repairs on the same item and report unresolved problems. Keep original copy and facts.

## Evidence and limits

4.5:1 is a conservative project text-readability target on solid backgrounds, inspired by W3C; not a universal marketing-image compliance requirement. Logos, pictures and actual viewing size need judgement. Creative distinction and conversion cannot be proved by geometry. Inspect the entire batch contact sheet as well as extremes.
